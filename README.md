# HR Workforce & Attrition Analytics Dashboard

## Project Overview
An interactive Power BI portfolio project built to analyze workforce composition, employee exits, hiring trends, compensation, performance, and attendance using a synthetic HR dataset.

## Objectives
- Analyze workforce size and employee demographics.
- Explore employee exits across departments and work modes.
- Identify hiring trends over time.
- Review salary and performance indicators.
- Analyze attendance patterns.
- Present findings and recommendations through an interactive dashboard.

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Modeling
- CSV datasets

## Dashboard Pages
1. **Overview** — workforce KPIs, department distribution, hiring trends, and compensation.
2. **Attrition Analysis** — exit counts, employee categories, and exit trends.
3. **Workforce & Compensation** — job roles, employee distribution, salary, and work mode.
4. **Performance & Attendance** — performance indicators, training, and attendance patterns.
5. **HR Insights & Recommendations** — key findings and suggested follow-up actions.

## Key Findings
- 650 unique employees after duplicate records were removed.
- Average employee age: 39.95 years.
- Overall attendance rate: 96.47%.
- Engineering recorded 12 exits, the highest department exit count in the analysis.
- 2024 recorded the highest hiring count, with 74 hires.

## Data Limitation
This project uses a synthetic practice dataset. The findings demonstrate analytical techniques and do not represent a real company. Recommendations are suggested actions for further investigation, not proven causes.
